## 📦 Автоматические бекапы

### В конце каждого дня:
```powershell
# Перейти в папку проекта
cd "C:\Users\glumi\OneDrive\Документы\Default Project\clothing-store"

# Сохранить изменения в Git
git add .
git commit -m "День X: описание что сделано"

# Создать резервную копию
$day = "dayX"
$backupPath = "..\backups\$day"
if (-not (Test-Path $backupPath)) {
    New-Item -ItemType Directory -Path $backupPath
}
Copy-Item -Recurse -Force . $backupPath
Write-Host "✅ Бекап дня $day создан"
```

### Сохрани этот скрипт как `backup.ps1` и запускай каждый вечер:
```powershell
.\backup.ps1
```
