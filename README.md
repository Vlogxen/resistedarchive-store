# Магазин Одежды - E-commerce

Интернет-магазин одежды с интеграцией Meta Pixel для качественной передачи данных в рекламные кабинеты.

## 🚀 Как запустить

1. Открой папку `clothing-store`
2. Дважды кликни на `index.html` — откроется в браузере
3. Или через терминал: `start index.html` (в PowerShell)

Установка программ НЕ требуется — работает сразу.

## 📱 Что есть сейчас

- ✅ Каталог товаров (8 позиций для примера)
- ✅ Корзина (сохраняется в браузере)
- ✅ Форма оформления заказа
- ✅ **Meta Pixel интеграция** — все события настроены:
  - `PageView` — просмотр страницы
  - `ViewContent` — клик по товару
  - `AddToCart` — добавление в корзину
  - `InitiateCheckout` — начало оформления
  - `Purchase` — завершение заказа
- ✅ Адаптивный дизайн (работает на телефонах)

## 🔧 Настройка Meta Pixel

1. Открой `index.html` в любом редакторе (Блокнот подойдет)
2. Найди строку `fbq('init', 'YOUR_PIXEL_ID');` (строка 19)
3. Замени `YOUR_PIXEL_ID` на свой ID пикселя из Meta Ads Manager
4. Найди еще одну строку с `YOUR_PIXEL_ID` (строка 24) — замени тоже
5. Сохрани файл

**Где взять Pixel ID:**
Meta Business Suite → События → Пиксели → скопируй ID (это цифры)

## 📝 Тестирование Meta Pixel

1. Установи расширение **Meta Pixel Helper** в Chrome
2. Открой свой сайт
3. Кликни на иконку расширения — увидишь какие события отправляются
4. Проверь: добавь товар в корзину → должно показать событие `AddToCart`
