# 📋 Инструкция по установке Git для бекапов

## Что такое Git?
Система для сохранения версий проекта. Как "точки сохранения" в игре — можешь вернуться к любой предыдущей версии.

## Установка Git

1. Скачай с https://git-scm.com/download/win
2. Установи (везде нажимай "Next", настройки по умолчанию подходят)
3. Перезапуsti PowerShell
4. Проверь: `git --version` — должна показаться версия

## Первая настройка (один раз)

```powershell
git config --global user.name "Твоё имя"
git config --global user.email "твой@email.com"
```

## Создание репозитория (первый раз)

```powershell
cd clothing-store
git init
git add .
git commit -m "Первая версия магазина"
```

✅ Готово! Первая версия сохранена.

## Каждый раз когда работаешь над проектом

### Перед началом работы (необязательно, но полезно):
```powershell
git status  # Посмотреть что изменилось
```

### После изменений — сохранить версию:
```powershell
git add .
git commit -m "Описание что сделал, например: добавил 5 новых товаров"
```

## Полезные команды

### Посмотреть историю сохранений:
```powershell
git log --oneline
```
Покажет список типа:
```
a1b2c3d Добавил новые товары
e4f5g6h Изменил цены
7h8i9j0 Первая версия магазина
```

### Вернуться к старой версии:
```powershell
git checkout a1b2c3d
```
(где `a1b2c3d` — код версии из `git log`)

### Вернуться обратно к последней версии:
```powershell
git checkout main
```

## Без GitHub/GitLab — локальные бекапы

Сейчас бекапы только на твоем компе в папке `.git` (скрытая).

**Чтобы не потерять при переустановке Windows:**
- Скопируй всю папку `clothing-store` на внешний диск
- Или загрузи на GitHub (отдельная инструкция ниже)

## Бонус: Загрузка на GitHub (облачный бекап)

### 1. Создай аккаунт на GitHub.com

### 2. Создай новый репозиторий (кнопка "+")
- Название: `clothing-store`
- Private (приватный, чтобы никто не видел)
- НЕ создавай README

### 3. В терминале:
```powershell
git remote add origin https://github.com/ТВОЙ_ЛОГИН/clothing-store.git
git branch -M main
git push -u origin main
```

### 4. Теперь каждый раз после коммита:
```powershell
git push
```

Это отправит изменения в облако. Даже если комп сломается — код в безопасности.

## Частые проблемы

**"nothing to commit"** — нет изменений для сохранения  
**"not a git repository"** — ты не в папке проекта, сделай `cd clothing-store`  
**"merge conflict"** — не должно возникнуть, если работаешь один

## Простая схема работы

```
Изменил код → git add . → git commit -m "что сделал" → продолжай работу
                                        ↓
                              (опционально: git push для облака)
```

Делай коммиты часто — после каждой законченной фичи или в конце дня.
