## 2️⃣ Настрой Meta Pixel (5 минут)

### Шаг 1: Получи Pixel ID
1. Зайди в Meta Business Suite: https://business.facebook.com
2. Настройки → События
3. Пиксели → скопируй ID (это просто цифры, например: 1234567890)

### Шаг 2: Вставь ID в код
1. Открой `index.html` в Блокноте или любом редакторе
2. Найди строку 19: `fbq('init', 'YOUR_PIXEL_ID');`
3. Замени `YOUR_PIXEL_ID` на твой настоящий ID
4. Найди строку 24: `src="https://www.facebook.com/tr?id=YOUR_PIXEL_ID&ev=PageView&noscript=1"`
5. Замени второй `YOUR_PIXEL_ID` на тот же ID
6. Сохрани файл

### Шаг 3: Проверь работу
1. Установи расширение **Meta Pixel Helper** для Chrome
2. Открой свой `index.html` в браузере
3. Кликни на иконку расширения — должен показать зеленую галочку
4. Добавь товар в корзину — увидишь событие `AddToCart`

## 3️⃣ Установи Git для бекапов (10 минут)

### Зачем это нужно?
Git сохраняет все версии проекта. Если что-то сломается — откатишься назад за 1 команду.

### Установка:
1. Скачай: https://git-scm.com/download/win
2. Запусти установщик (везде "Next")
3. **Закрой и снова открой PowerShell** (важно!)
4. Проверь: `git --version`

### Первая настройка:
```powershell
git config --global user.name "Твое имя"
git config --global user.email "твой@email.com"
```

### Создай первый бекап:
```powershell
cd "C:\Users\glumi\OneDrive\Документы\Default Project\clothing-store"
git init
git add .
git commit -m "День 1: Базовая версия магазина"
```

✅ Готово! Первая версия сохранена.

## 5️⃣ План на завтра (День 2 - 24 сентября)

### Подготовь фото товаров:
1. Зайди на https://unsplash.com или https://pexels.com
2. Найди 8-10 фото одежды (футболки, джинсы, платья, обувь)
3. Скачай в хорошем качестве
4. Создай папку `clothing-store/images/products/`
5. Сохрани фото туда с простыми именами: `tshirt-1.jpg`, `jeans-1.jpg`, etc.

### Обнови товары:
1. Открой `js/products.js`
2. Замени эмодзи на пути к фото:
   ```javascript
   image: 'images/products/tshirt-1.jpg',
   ```
3. Добавь больше товаров (минимум 20)

## 🆘 Если что-то пошло не так

### Сайт не открывается:
- Убедись что все файлы на месте в папке `clothing-store`
- Попробуй другой браузер (Chrome, Firefox)
- Открой консоль браузера (F12) — смотри ошибки

### Meta Pixel не работает:
- Проверь что заменил `YOUR_PIXEL_ID` на настоящий
- Установи Meta Pixel Helper расширение
- Очисти кеш браузера (Ctrl + Shift + Delete)

### Git команды не работают:
- Убедись что установил Git
- **Закрой и снова открой PowerShell** после установки
- Проверь: `git --version`

### Backup.ps1 не запускается:
```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```
Это разрешит запуск скриптов.
